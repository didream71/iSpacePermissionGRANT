# iSpacePermission — выдача разрешений Android через ADB

Графическое Windows-приложение (GUI) для массовой выдачи разрешений Android-приложению через ADB — в один клик. По сути это удобная оболочка над скриптом [`grant_permissions.sh`](grant_permissions.sh): подключаемся к устройству, выбираем приложение и выдаём ему все разрешения, которые можно выдать через `adb`, включая особые AppOps (наложение поверх окон, установка из неизвестных источников и т.д.).

Изначально разрабатывалось для автомобильного головного устройства (ГУ) на Android.

## Возможности

- 🔌 Подключение по **USB** или **Wi-Fi** (`adb connect <ip>`)
- 📦 Список установленных приложений (сторонние + системные)
- 🔑 Предпросмотр всех запрашиваемых разрешений выбранного приложения
- ✨ Выдача **всех** разрешений одной кнопкой:
  - `runtime`-разрешения — через `pm grant`
  - особые разрешения — через `appops set` (SYSTEM_ALERT_WINDOW, WRITE_SETTINGS, MANAGE_EXTERNAL_STORAGE, REQUEST_INSTALL_PACKAGES, GET_USAGE_STATS)
- 🔍 Проверка статуса AppOps после выдачи
- 🚀 Перезапуск приложения на устройстве
- 📜 Подробный цветной лог
- ADB встроен в exe — отдельная установка platform-tools не нужна

> **Примечание.** Через `adb` выдаются только `runtime`-разрешения и AppOps. Обычные (`normal`) разрешения Android выдаёт автоматически при установке, а `signature`/системные — только при совпадении подписи приложения; их нельзя выдать никаким adb-инструментом. Это штатное поведение Android, а не ошибка.

## Скачать

Готовый `iSpacePermission.exe` — на вкладке [**Releases**](../../releases). Это один самодостаточный файл (ADB встроен внутрь). Требуется .NET Framework 4.7.2 (входит в состав Windows 10/11).

## Использование

1. На устройстве включите **Отладку по USB** (или **по сети**).
2. Подключите устройство по USB **или** нажмите «Подключить по IP» и введите IP (например, `192.168.31.135`).
3. Нажмите «Загрузить список приложений» и выберите нужное.
4. Нажмите «✨ Выдать ВСЕ разрешения».

## Сборка из исходников

Проект — **.NET Framework 4.7.2 / WinForms**. Открыть `iSpacePermission.slnx` в Visual Studio и собрать, либо из командной строки:

```powershell
& "C:\Program Files\Microsoft Visual Studio\18\Community\MSBuild\Current\Bin\MSBuild.exe" iSpacePermission.csproj /t:Rebuild /p:Configuration=Release
```

Результат — `bin\Release\iSpacePermission.exe`. Бинарники ADB (`adb/`) встраиваются в exe как ресурсы и распаковываются в `%TEMP%\iSpaceADB` при запуске.
